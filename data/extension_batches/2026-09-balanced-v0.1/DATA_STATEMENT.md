# Data statement

This extension adds ten blank administrative forms as normalized HTML/JSON benchmark samples. It does not contain completed real-world forms, real applicant records or identifiers, source logos, or the original PDF files. Stage 2-4 example values are synthetic and must not be used as actual filings.

The original sources and their reuse notices are listed in [SOURCE.md](SOURCE.md). Attribution to those issuers and links should be retained when redistributing the normalized samples. The extension is an adaptation and has no government endorsement. Sample-specific uncertainty and historical status are noted in [manifest.json](manifest.json).

No model baseline scores are included. The seven supplied workflow stages can be used with the benchmark's existing task definitions and evaluation code.
