INSTRUCCIONES PARA COMPLETAR EL FORM. DA 8110-12, SOLICITUD DE CERTIFICADO TIPO, CERTIFICADO DE PRODUCCIÓN O CERTIFICADO TIPO SUPLEMENTARIO
El Formulario DA 8110-12 se utiliza para la solicitud de un CT, CP y CTS, para enmendar el CT, CP, CTS o para modificar un CTS. La solicitud para un CT y un CP se puede hacer al mismo tiempo. Se deben completar los casilleros que correspondan para cada tipo de certificado de la siguiente manera.
Casilleros 1, 2, 3, 4, 5 y 8 para un CT o enmienda a un CT;
Casilleros 1, 2, 3, 6 y 8 para un CP;
Casilleros 1, 2, 3, 4, 7 y 8 para un CTS o una enmienda al CTS.
Casillero 1. Marque el casillero que corresponda.
Casillero 2. Marque el casillero que corresponda.
Casillero 3. Ingrese el nombre de la persona, corporación u organización de quien solicita el CT, CP o CTS, la enmienda al CT, CP o CTS, o modificación al CTS. Este nombre se colocará en el certificado exactamente como se escribió aquí.
NOTA: Solo el titular del CT puede solicitar una enmienda al CT original. Si es otra persona, que no sea el titular de CT, esta persona debe solicitar un CTS. Además, solo los titulares de los CTS pueden solicitar la modificación de sus propios CTS.
Casillero 4. Ingrese el domicilio de la persona, corporación u organización de quien solicita el CT, CP o CTS, la enmienda al CT, CP o CTS, o modificación al CTS.
NOTA: No se aceptará un apartado postal.
Casillero 5. Complete este casillero si la solicitud es para un CT o una enmienda al CT. Dejar en blanco si la solicitud es para un CP, CTS o una enmienda al CTS.
Casillero 6. Complete las partes a, b y c de este casillero si la solicitud es para un CP. Indique el número de CP si la solicitud es para una incorporación a un CP. Déjelo en blanco si la solicitud es para un CP original. Indique el número de CT/CTS si lo conoce al momento de la solicitud; de lo contrario, déjelo en blanco. Consultar al RAAC Parte 21 Secciones 21.45 y 21.119.
NOTA: Normalmente no se requiere un CP para la producción de partes para un CTS, generalmente estas se fabrican bajo una autorización de AFP.
Casillero 7. Complete las partes a, b, c y d si la solicitud es para un CTS.
Casillero 8. Firmar por quien solicita oficialmente la certificación. La firma debe ser del titular o de una persona debidamente autorizada para firmar por el titular, la empresa o la corporación.
