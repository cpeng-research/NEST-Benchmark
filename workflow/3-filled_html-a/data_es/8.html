Formulario PS 2.68 (dorso) · Instrucciones para completar el formulario
Datos de la/del alumna/o - paciente: completar CUIL, apellido/s y nombre/s, fecha de nacimiento, domicilio, teléfono y/o correo electrónico.
Datos de escolaridad: indicar ciclo lectivo y seleccionar tipo de certificado. Para Primaria / EGB completar Grado; para Secundaria / Polimodal completar Año.
Formación / Superior comprende formación profesional, curso de capacitación, terciario o universitario. Escolar diferencial corresponde a Escuela Diferencial. Especial comprende rehabilitación, maestra/o particular, taller protegido o formación laboral.
Datos de la escuela: completar sólo para Escolar, Formación / Superior o Escolar diferencial. Nombre del curso / carrera sólo para Formación / Superior. Datos del tratamiento: sólo para Especial.
Este formulario debe completarse con letra clara y en imprenta, sin tachaduras ni enmiendas.
