Description of Trainee/Intern's role for this program or phase
The intern will support the data science unit in building and maintaining analytics solutions for client reporting and internal decision-making. Responsibilities include gathering and profiling data from relational databases and APIs, developing and documenting ETL workflows in Python and SQL, constructing interactive dashboards in Tableau/Power BI, and prototyping predictive models (e.g., logistic regression and random forests) for customer retention and demand forecasting. The intern will write clean, version-controlled code (Git), participate in sprint planning and daily stand-ups, prepare technical documentation and data dictionaries, validate data quality using reproducible checks, and present findings to stakeholders. Additional duties include optimizing SQL queries, assisting in deployment of scheduled jobs, implementing data governance best practices, and contributing to team retrospectives and knowledge-sharing sessions.
Specific goals and objectives for this program or phase
1) Achieve proficiency in data ingestion and transformation by building at least two end-to-end ETL pipelines (source extraction, cleansing, schema mapping, load) using Python (pandas) and PostgreSQL by week 10. 2) Design and publish two interactive dashboards with drill-downs and KPI alerts in Tableau or Power BI that meet stakeholder requirements and pass usability review by week 16. 3) Develop and evaluate a supervised learning prototype (baseline + one advanced model) with appropriate cross-validation and performance metrics (AUC/F1) and deliver a technical report by week 20. 4) Improve query performance on a high-volume reporting table by at least 30% through indexing and query refactoring, demonstrated by before/after benchmarks by week 18. 5) Demonstrate effective communication by delivering one mid-phase readout and one final presentation, accompanied by well-structured documentation, code comments, and a reproducible environment file.
